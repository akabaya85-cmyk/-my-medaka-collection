My Medaka Collection 初期動作版
1. このフォルダをGitHub Pages等のHTTPSホスティングへ公開します。
2. iPhoneのSafariで公開URLを開き、共有→ホーム画面に追加。
3. 飼育状態を設定し、詳細から個人用写真を登録します。
4. バックアップ保存は写真を含むJSONです。定期的にファイルアプリ等に保管してください。
5. CSVの列は name,traits,url です。既存品種名と完全一致する場合は追加しません。
注意：収録40件は初期サンプルであり、全件の正式分類・説明・写真の検証は未完了です。写真は収録していません。
注意：Safariの保存容量には制限があります。大量画像は容量超過するため、1000枚保存にはIndexedDBや画像圧縮への改修が必要です。
注意：この版のCSVパーサはカンマを含む引用セルに非対応です。

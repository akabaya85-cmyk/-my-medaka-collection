My Medaka Collection — 機能統合版（2026-10-24）

【大切】
アプリ機能をまとめた配布版です。初期データは40件で、改良メダカWEB図鑑の約1,000品種を網羅していません。掲載品種の権利確認・品種情報の照合も未完了です。『1,000品種完成版』ではありません。

【機能】
・全図鑑／飼育中／過去に飼育／飼いたい／お気に入り
・検索、特徴フィルタ、名前順／更新順、ページ分割表示
・各品種の説明、飼育ポイント、別名、出典リンク、メモ
・写真複数枚の登録、端末内での圧縮、同名ファイルによるまとめて登録
・CSVによる品種追加（ヘッダはname,aliases,traits,kind,description,care,url）
・写真込みJSONバックアップと復元
・既存v1/v2のデータを可能な範囲で自動移行
・オフライン表示用PWA

【更新方法】
1. 現在のアプリからバックアップを保存（記録がある場合）。
2. ZIPを解凍し、中のファイルすべてを既存GitHubリポジトリのルートに上書きアップロード。
3. GitHub Pagesのデプロイ完了後、アプリを再起動。
4. 古い画面が残る場合は一度オンラインで再読み込み。
※Safari版とホーム画面版では保存領域が異なる場合があります。写真・メモの引き継ぎはバックアップと復元が確実です。

【写真の一括登録】
ファイル名（拡張子を除く）が品種名と完全一致する写真だけ自動登録します。例えば「楊貴妃.jpg」。一致しない写真は個別の詳細画面から登録できます。

【保存と注意】
データは端末のブラウザ保存領域にあります。削除・端末交換・容量不足で失われる可能性があります。JSONバックアップは画像枚数が多いと大容量になります。大容量バックアップは実機検証が必要です。
GitHubに個人写真をアップロードしないでください。外部図鑑の画像や解説を無断で一括取得・再配布しないでください。
